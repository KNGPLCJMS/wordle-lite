## How to play
Your goal is to guess a 5 letter word in 6 tries. After every the guess, every letter is colored. Green means it's the correct letter in the correct place. Yellow means the letter is in the word but in the wrong place. Grey means it is not in the word.
## Features
- Animated letters when guess is submitted
- The same word list as the official game
- Simple keyboard display
- Works Offline
