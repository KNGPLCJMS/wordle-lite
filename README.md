## 🎯Features
- Keyboard display
- Random Word Selection
- Animated letters
- Over 2300 words
## ⚙️How it works
It has two seperate wordlists, one for answers and another for guesses. It checks answers by comparing two arrays. Both the keyboard and the boxes are drawn by an array. Everything is local and no local storage is used.
